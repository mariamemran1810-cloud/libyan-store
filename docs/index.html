تشغيل المشروع محليًا

ثلاثة أوامر فقط — بدون Composer وبدون إعدادات معقّدة.

git clone https://github.com/mariamemran1810-cloud/libyan-store.git
cd libyan-store
copy .env.example .env        # ثم عدّلي APP_URL
php scripts/migrate.php       # الجداول + البيانات التجريبية
php -S 127.0.0.1:8000 -t public public/index.php

حسابات التجربة: admin@example.com — seller@example.com — customer@example.com وكلمة المرور ChangeMe123!
